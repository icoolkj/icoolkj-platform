## 平台定位

iCoolKJ Platform 是一套面向企业中后台场景的 **通用开发平台**，用于作为多个业务系统的统一底座，支持后续快速复制、扩展与国产化迁移。

---

## 适用范围

- 后台管理系统
- 企业内部业务系统
- SaaS 管理后台
- 项目管理、客户管理、知识库、工单、流程类系统
- 需要统一用户、权限、**租户**、字典、日志、文件、异步任务、**安全治理**能力的项目

---

## 核心目标

1. **一套底座，多项目复用** — 通用能力下沉，避免每个项目重复建设
2. **通用能力下沉，业务能力上浮** — 平台层与业务层清晰分离
3. **统一技术栈、统一规范、统一表结构** — 降低团队协作与维护成本
4. **明确许可边界** — 源码公开、非商业学习研究、保留商业授权
5. **支持多租户扩展** — 共享库共享表，`tenant_id` 隔离
6. **支持安全治理与访问控制** — IP 白名单/黑名单，平台级与租户级规则
7. **支持长期维护与二次开发** — 架构可持续演进
8. **支持后期国产化迁移与适配** — 关键中间件抽象边界，以替换实现为主

---

## 最终结论（V2.2 基线）

| 维度 | 标准 |
|------|------|
| 租户 | 一账号一租户，`tenant_id='0'` 为平台级 |
| 管理员 | 平台/租户管理员边界清晰，超级管理员绕过规则明确 |
| 权限 | 菜单导航与权限码分离，M/C/F 三类资源 |
| 唯一索引 | 含 `deleted`，支持逻辑删除后重建 |
| 安全 | IP 规则、登录锁定、密码策略、日志脱敏 |
| 初始化 | Flyway 基线一次性定死表结构、角色、菜单、参数、IP 策略 |
| 国产化 | 数据库/缓存/异步/文件/第三方通过抽象接口解耦，预留适配边界 |
